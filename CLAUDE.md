## Design rules (from Ilan)
- **No small "label" chips or kicker tags above or near headings.** No pills like "NEW", "Coming soon", "What's inside", "Weekly poll", "For parents", "Log out" sitting on top of a title. They look AI-made. Use the heading alone, with plain text under it if needed.
- Keep the look of the game: chunky rounded buttons with a darker bottom edge, Lilita One headings, Fredoka body text, bright game colours, and panels styled like the in-game windows.
- Prefer real 3D (the Jumpi character from `/blobby.glb`, three.js) or in-game art over generic emoji/icon illustrations.
- Avoid generic "AI" layouts (rows of identical cards with emoji icons). Design something that feels like part of the game.

## Security (the October 2026 audit, all fixed; keep these rules)
- **Never crash the server**: every socket handler is wrapped (plaza.js `io.on("connection")` replaces `socket.on`), `unhandledRejection` / `uncaughtException` only log (server.js). Look-ups by a name the player sends use `Object.hasOwn(TABLE, key)` (GAMES, JOBS, PET_BY_ID, UPGRADE_BY_ID, PRODUCT_BY_ID, LOOK_SLOTS, QUEST_BY_ID): `constructor` must never pass.
- **Items can't be duplicated**: `User` has `optimisticConcurrency` (a stale `save()` fails with VersionError → 409 "Something got in the way", server.js error handler). Atomic updates that add items also `$inc: { __v: 1 }`. Wearing (`/inventory/equip`) retries on a clash. Store-only items (`exclusive`, auras 8-9) can't be traded; accounts under 2 days can't trade; the 60-furniture limit is inside the buy update and checked on trades.
- **Chat filter** (public/shared/profanity.js): `plainText()` removes invisible characters and turns any script's digits into 0-9; phone numbers sent in pieces are kept as pieces (`2|054|123`); emails written "at … dot …"; links (`link`), other apps like Snapchat/Instagram/TikTok/Discord (`app`) and grooming asks (pictures, secrets, alone, meeting: `unsafe`) are blocked with the "keep safe" window (no strike). Russian (Cyrillic or Latin) and Arabic swear words. `riskText()` (age, school, city, dating) is sent but flagged. Flags go to /admin → Player reports as `where: "filter"` (`flagChat` in plaza.js; unsafe = urgent "grooming", risk = "flagged").
- **Real addresses**: routes/ip.js. `req.ip` = CF-Connecting-IP only when the connection came from the tunnel (127.0.0.1) or a Cloudflare range. Login also locks one account name after 8 wrong passwords in 15 minutes from one address (40 from all addresses together). `isHttps(req)` decides the `Secure` cookie flag; HSTS on the real domain.
- **Tokens** (routes/auth.js): each has `typ` (login / tab / verify / acc; admin unlock `k: "admin"`) and `readToken(token, kind)` only accepts its own kind (old tokens without typ are recognised by their fields). Login and tab tokens have a `jti`; `/logout` (JSON only) puts them on the `Revoked` list (models/Revoked.js, loaded at start) and closes their game windows (`endSessions`). Tab tokens last 12 h and are renewed by any call (header `x-jumpi-tab-new`, read by `api()` in the game); an expired tab token falls back to the browser's login cookie (x-jumpi-as / whoami still check the account). A new password closes every game window (`kicked:password`). Passwords: 8-72 characters (bcrypt), not the username. The email code counts every try atomically.
- **Admin**: the /admin panel API accepts only the login cookie (never a game tab's token). In the game, an admin types their password (`admin:unlock`, 30 minutes per window) before coins, gift codes and permanent bans. Deleting an account needs the admin's password; an admin can only remove the admin role from admins whose account is newer than theirs. Report alerts go to admins only (not moderators), without the reporter's name, never to the reported player.
- **Homes**: `User.homeAccess` = friends (default) / all / closed, the blue button in the home bar; "Send out" on the player card in your own home (only out of the room right now: they stay friends and can come back if the home's setting allows it). `mayVisit()` in plaza.js is checked on `/api/home/of` and on joining the room; a block or a stricter setting takes visitors out on the server (`sendOut`). - **Pages**: every page we send has a CSP made from the page's own inline scripts (sha256, `cspFor` in server.js), so **no inline `onclick=` attributes and no scripts from other sites**. three.js is served from `public/vendor/three/` (r160 from the official GitHub tag; importmaps point there). The routed pages (index.html, admin/, site/*.html) are never served as plain files, whatever the spelling. The live connection only takes pages from our own hosts and messages up to 16 KB; typing / hop / join / leave / chat have per-window limits.
- **Coins**: birthday coins only for accounts older than 30 days (the hat for everyone); the cave chest needs 10 s without a position jump (`warpAt` in plaza.js "move"); the same two players can play at most 8 board games a day; mini-game XP only for a score above 0. - **Test hooks** (`?questtest`, `?beachtest`…) use `testKey()` and don't work on jumpigames.com.

- Keyboard shortcuts use `e.code` (KeyM map, KeyR rotate furniture, KeyP phone), so they work with a Hebrew keyboard. Keep it that way for any new letter shortcut.
- Wardrobe / tags: tapping what you're wearing takes it off (`selectItem` → the "none" tile); the worn tile has `.worn` (green outline + check).
